# Backend Forge Lab Docs

這個資料夾放 Backend Forge Lab 的長期文件。文件依用途分成三類，避免 roadmap、設計指南與實作追蹤混在同一份文件裡。

## 文件分類

| 分類 | 位置 | 用途 |
|---|---|---|
| Introduction | `docs/introduction/` | Lab 會用到的 infrastructure 基本概念、操作入口與觀察方式 |
| Proposal | `docs/proposal/` | 學習方向、能力模型、長期 roadmap |
| Guide | `docs/guide/` | Lab 設計規則、repository structure、runner lifecycle |
| Task | `docs/task/` | 目前完成狀態、active labs、backlog、工具評估 |

## 建議閱讀順序

1. `proposal/README.md`
2. `guide/README.md`
3. `introduction/`
4. `task/README.md`

Proposal 說明「要往哪裡學」，Guide 說明「Lab 要怎麼設計與初始化」，Introduction 說明「Lab 用到的基礎設施怎麼理解」，Task 說明「現在做到哪裡」。
