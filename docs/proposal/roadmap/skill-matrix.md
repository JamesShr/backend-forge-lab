# Skill Matrix

星等定義：

- 五星：Senior Backend 核心能力，應優先投入
- 四星：高價值能力，建議至少達 L2 到 L3
- 三星：重要周邊能力，依需求深入
- 二星：知道概念即可，進階視職涯方向
- 一星：特定情境才需要

## 建議目標深度

| 領域 | 建議目標 | 優先級 |
|---|---:|---:|
| Backend Engineering | L4 | 五星 |
| Database Engineering | L3 | 五星 |
| Distributed Systems | L3 | 五星 |
| Messaging / Event-driven | L3 | 五星 |
| SRE / Observability | L3 | 五星 |
| DevOps / Delivery | L3 | 四星 |
| Cloud Engineering | L2-L3 | 四星 |
| Kubernetes | L2-L3 | 四星 |
| Backend Security | L3 | 四星 |
| AI Engineering | L2-L3 | 三星 |

## 核心能力分組

```text
Backend + Database + Distributed Systems
                ↓
        Senior Backend Core

SRE + DevOps + Cloud + Kubernetes
                ↓
       Production Engineering

Security + AI
                ↓
          Capability Extension
```

## 使用方式

Skill matrix 不應被當成待辦清單逐項完成。它的用途是決定 lab 的優先順序與深度：

- 五星主題優先轉成 production-like lab。
- 四星主題至少要能整合進 backend workflow。
- 三星以下主題先保留概念理解，等實務需求出現再深入。
